# Follow-up Message Library

## No reply
“Following up because the workflow issue I mentioned is usually measurable quickly. If it is not a priority, I can close the loop.”

## Interested but busy
“Understood. I can send a one-page outline with the expected inputs, implementation path and measurable outcome so you can review asynchronously.”

## Asked for details
“Here is the short version: current state, proposed change, implementation effort, success metric and next decision.”

## Proposal sent
“Checking whether any commercial, scope or implementation question is blocking a decision.”

## Not now
“Understood. I will close this for now rather than continue following up.”
